# Бот-помощник техникума «Автоматика»

Telegram-бот с кнопками: разделы → подтемы → популярные вопросы → ответ.
Если человек пишет текстом, а ответа нет, бот предлагает сайт и контакты.

## Файлы
- `faq.py`: все тексты (вопросы, ответы, контакты). **Правите только его.**
- `bot.py`: логика бота и меню.
- `requirements.txt`: зависимости.

## Как править ответы
В `faq.py` у каждого вопроса есть признак `True` или `False`.
`False` значит «ответ не проверен»: под ним появится пометка `[уточнить]`.
Сверьте ответ с сайтом или приёмной комиссией, поправьте текст и поставьте `True`.

## Запуск на компьютере
```
pip install -r requirements.txt
set BOT_TOKEN=ваш_токен        (Windows)
export BOT_TOKEN=ваш_токен     (Mac/Linux)
python bot.py
```

## Деплой на Render (бесплатно)
1. Создайте репозиторий на GitHub и загрузите туда эти файлы.
2. На render.com: New → Web Service → выберите репозиторий.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Environment → добавьте переменную `BOT_TOKEN` (токен из @BotFather).
6. Deploy. Бесплатный сервис засыпает после простоя, первый ответ может прийти с задержкой.
